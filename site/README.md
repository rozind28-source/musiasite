# Шар&Ко — PWA-магазин воздушных шаров

Демонстрационный многостраничный сайт (41 страница) в виде полноценного PWA-приложения.
Дизайн — оригинальная реконструкция структуры mrsair.ru; тексты, логотип и изображения созданы с нуля.

## Как запустить

```bash
cd site
python3 -m http.server 8000
# открыть http://localhost:8000
```

PWA (service worker, установка) работает только по HTTP(S): `localhost` подходит,
в продакшене нужен HTTPS. При открытии файлов двойным кликом (file://) сайт тоже
откроется, но без service worker и манифеста.

## Установка как приложения

- **Android / Chrome:** кнопка «Установить» в шапке появляется автоматически
  (событие `beforeinstallprompt`) или меню браузера «Добавить на главный экран».
- **iOS / Safari:** «Поделиться» → «На экран “Домой”» (подхватятся `apple-touch-icon`
  и standalone-режим).
- После установки приложение открывается без адресной строки (`display: standalone`).

## Офлайн-режим

- `sw.js` при установке прекэширует все 41 страницу, манифест, иконки и все изображения (~5 МБ).
- Навигация: сеть → кэш → `offline.html` (фирменная офлайн-страница).
- Остальные ресурсы: кэш → сеть (с доукладыванием в кэш).
- Корзина хранится в `localStorage` и переживает офлайн.

## Структура

- `index.html`, `shop.html`, `soberisam.html`, `delivery.html`, `about.html`,
  `contacts.html`, `privacy.html`, `offer.html`, `offline.html`
- `catalog/*.html` — 16 категорий, `product/*.html` — 17 карточек товаров
- `manifest.webmanifest`, `sw.js` — PWA-обвязка
- `img/` — JPEG-фото (сжаты с 75 МБ до 2.5 МБ) и иконки приложения
- `src/style.css`, `src/main.js` — исходники стилей и скриптов (вшиваются в страницы)
- `build.py` — генератор: правите данные/шаблоны → `python3 build.py` пересобирает всё,
  включая manifest и precache-лист service worker.
